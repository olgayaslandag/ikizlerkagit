# 2026-10-28-agent-config.md

## Goal
Configure the `.opencode/` agents for the project.

## Tasks
1. Review existing agent definitions in `.opencode/`.
2. Identify any missing or misconfigured agents.
3. Create or update agent configuration files as needed.
4. Validate the configuration.
5. Execute build subagents to apply changes.

## Acceptance Criteria
- All agent definitions are correctly referenced and functional.
- No breaking changes without user confirmation.
- Configuration files are syntactically correct.
